# DSH rc.2 能力中心：源码核查

核查基线：官方仓库 `deepseek-ai/deepseek-harness`，标签 `dsh-v0.2.1-rc.2`，提交 [`687f282e8625c6b8d11ff58211a90524be2e4317`](https://github.com/deepseek-ai/deepseek-harness/tree/687f282e8625c6b8d11ff58211a90524be2e4317)。以下是静态源码核查；未运行安装、HMR 或 Windows 测试，未验证断网安装。链接均固定到该提交。

- **Skills：已有文件系统监听。** `skill-filesystem` 默认 `watch: true`、`watchUsePolling: false`，发现项目 `.dsh/skills`、`.agents/skills`、自定义目录及用户目录。列举技能时建立监听；Chokidar 监听新增、修改、删除等事件并调用 provider 的 `invalidate()`，技能正文在 `get()` 时读取。它提供目录发现与目录缓存失效机制，不能据此声称所有支持文件都递归热执行；监听深度为 1，也可关闭监听。[默认配置与发现/读取](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/skill/skill-filesystem/src/index.ts#L75-L87)、[目录来源](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/skill/skill-filesystem/src/index.ts#L185-L263)、[监听及失效通知](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/skill/skill-filesystem/src/index.ts#L490-L598)。

- **Plugins：安装包与激活层有明确区分。** Bundle 在 `package.json` 中声明 `dsh.bundle.patch`，值为一个包内 patch 路径或有序路径数组。`installBundle()` 安装后检查 bundle 元数据、版本兼容性和 patch，默认选入 profile；缺少 bundle 声明会报 `not-bundle` 并恢复 manifest/lockfile，不能把任意 npm 包当作已启用插件。激活失败发生在安装成功之后时，已保存的依赖和选择可能保留。[patch 解析](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/boot/app-boot/src/profile.ts#L51-L74)、[安装、检查与激活](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/boot/plugin-manager/src/index.ts#L518-L648)。

- **本地 tgz 入口存在；完整离线交付仍需另行验证。** Spec 解析器接受绝对本地 `.tgz` / `.tar.gz`（含 `file:`）及 HTTP tarball；相对本地路径被拒绝。安装实际执行 `pnpm add <spec>` 和 registry 参数，该调用没有自动附加 `--offline`。**由源码推断**：一个本地 tgz 只解决顶层包的来源，未随包交付或未缓存的依赖仍可能需要 registry；应在目标机验证完整传递依赖、peer 兼容及构建脚本所需资源，不能承诺“拷贝一个 tgz 即可离线安装”。允许的构建脚本效果也不等于 manifest/lockfile 回滚能撤销。[tarball 与路径规则](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/boot/plugin-manager/src/install-spec.ts#L10-L30)、[绝对路径校验](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/boot/plugin-manager/src/install-spec.ts#L60-L82)、[pnpm add 调用](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/boot/plugin-manager/src/index.ts#L570-L581)、[构建与恢复限制](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/boot/plugin-manager/README.md#L64-L69)。

- **HMR：以返回结果判断生效，不能统一宣称免重启。** 变更分别返回 `changed` 和 `application`；有 HMR 时调用 `reconcileProfile()`，无 HMR 时为 `restart-required` / `no-hmr`。即使有 HMR，仍可能因 `package-moved`、`host-module`、`unmanaged-plugin`、`module-comparison` 要求重启；导入或启动失败则可返回 `failed`。有 HMR 时，对已能识别且已安装的包拒绝覆盖安装（`already-installed`），更新通常需先移除再安装；未知包名的 git/tarball 存在安装后才识别的分支。因此“安装成功”“配置已保存”“运行态已应用”应分开呈现。[结果字段与重启原因](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/boot/plugin-manager/src/types.ts#L28-L35)、[运行态判定](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/boot/plugin-manager/src/index.ts#L881-L924)、[覆盖安装保护](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/boot/plugin-manager/src/index.ts#L540-L545)、[HMR 核对模块与重组](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/boot/hmr/src/index.ts#L925-L971)。

- **Python：工具返回内置运行时位置及构建清单。** `load_workspace_dependencies` 的 `python` 是解释器绝对路径，`pythonPackages` 是 `site-packages` 目录路径，`pythonDistributions` 是 `runtime.json` 记录的内置发行包版本映射，明确排除用户后装包；不能把这张表当作当前环境完整的 `pip list`。工具不修改 PATH 或包管理器设置，首次调用可能准备/安装 payload，随后复用准备结果，并非通用 Python 包管理 API。Windows 路径分支存在，但本次未运行验证。[字段定义](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/skill/tool-workspace-dependencies/src/index.ts#L32-L57)、[路径和版本映射](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/skill/tool-workspace-dependencies/src/index.ts#L178-L197)、[工具执行](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/skill/tool-workspace-dependencies/src/index.ts#L280-L318)。

- **Market：索引来源联合只有 npm/git。** `MarketSource` 仅支持 `type: 'npm'`（可指定 registry）或 `type: 'git'`（HTTPS 仓库、固定 40 位 commit、可选包目录），解析器拒绝其他类型。因此安装接口接受本地 tgz，不代表 format-1 市场索引能声明 tgz、本地技能目录或 Python wheel。[来源类型](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/util/plugin-market-index/src/types.ts#L43-L58)、[实际解析限制](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/util/plugin-market-index/src/index.ts#L191-L205)。

**架构建议（非 rc.2 已有实现）：** 能力中心可统一展示 Skills、插件与 Python 环境，但分别接入目录发现/失效通知、bundle 安装与运行态结果、运行时路径与环境盘点。离线 tgz 导入入口、用户增装 Python 包盘点及本地信息插件均需另行设计验证；本笔记不实现这些功能，也不将其视为源码已有能力。
