DSH 能力中心内网分发

只读服务：提供固定目录、能力制品、核心版本索引和稳定引导插件。没有账号、上传或远程安装接口。

首次安装

  1. 打开 DSH“插件”，选择“添加插件”。
  2. 粘贴稳定引导插件 tgz 地址。
  3. 安装并启用，按 DSH 返回结果决定是否重启。
  4. 打开侧栏“能力中心”，填写本页基础地址。

从旧管理器迁移

若曾安装 capability-center-demo，请先在 DSH 插件页停用并移除旧管理器一次。报告格式、本机系统信息和 Tabulate 会从本机回执与 profile 检测并在新账本中显示；不要删除这三项能力或 DSH 配置。

后续更新

频繁更新的核心通过页面顶部“检查更新 / 下载更新”暂存。新版引导会串行停止旧核心、验证候选并回退失败版本，成功后刷新 DSH。旧引导仍可在下次启动 DSH 时兼容激活。稳定引导插件只在升级引导能力或协议时从 DSH 插件页人工替换。
